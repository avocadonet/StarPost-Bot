
# Stars Post Bot: Попытка №2 — прагматичный минимализм после оверинжиниринга

> **Статус проекта:** Активен / MVP готов к бою.  
> **Концепция:** Радикальное упрощение архитектуры. Полный отказ от внешнего фиатного эквайринга, вебхуков и микросервисных контрактов в пользу нативной экономики **Telegram Stars (XTR)** и легковесного монолита.  
> **Роль ИИ:** 100% генерация (от проектирования ТЗ и пользовательских сценариев до итоговой кодовой базы) в рамках одного контекста.

---

## 1. Предыстория: работа над ошибками первой попытки

Первая итерация проекта (`Reklama Bot Platform`) была амбициозным архитектурным экспериментом по вайб-кодингу распределенной системы с эквайрингом Т-Банка, фискализацией по 54-ФЗ, паттерном Transactional Outbox и жесткой изоляцией модулей (`Package-by-Feature`). Она доказала главное: когда пытаешься с нуля заставить рой ИИ-агентов строить сложный энтерпрайз, ты тонешь в бюрократии контрактов, DTO и верификации «нейрослопа».

**Эта попытка №2 — осознанный разворот на 180 градусов.**  
Вместо того чтобы бороться с инфраструктурной сложностью, мы просто вырезали её на уровне бизнес-логики:

* **Никакого внешнего эквайринга и 54-ФЗ:** оплата переведена на внутреннюю валюту платформы — **Telegram Stars (`XTR`)**. Telegram сам выступает платежным шлюзом.
* **Никаких вебхуков, SSL-сертификатов и белого IP:** бот работает на обычном `Long Polling` в рамках одного рантайм-процесса.
* **Никаких очередей и брокеров сообщений:** публикация происходит синхронно в момент подтверждения платежа (`SuccessfulPayment`), а при любом сбое отправки срабатывает мгновенный автоматический возврат звезд через нативный метод `refundStarPayment`.
* **Никаких медиа-хранилищ:** жесткий фильтр только на текстовые сообщения (`message.text` до 4096 символов) с побайтовым сохранением нативного форматирования через `message.entities`.

## 2. Как создавался этот бот (ИИ-пайплайн курильщика vs здорового человека)

Если в первом проекте использовалась сложная иерархия из «ИИ-Архитектора» и «ИИ-Исполнителей» с заморозкой модулей, то здесь процесс был линейным и занял минимум времени:

1. **Генерация ТЗ ботом:** ИИ-ассистенту была поставлена задача сформулировать самодостаточное Техническое Задание на монолитный сервис без оверинжиниринга. Нейросеть сама спроектировала граф состояний FSM, спецификацию платежей `Payments v2` и матрицу граничных сценариев (Edge Cases).
2. **Генерация кода в один проход:** Поскольку весь проект укладывается в ~6 компактных файлов, ИИ сгенерировал всю кодовую базу целиком, удерживая полный контекст в голове. Без рассинхрона контрактов и потерянных импортов.

### Что это дало на практике:
Когда объем кодовой базы соразмерен окну внимания человека и модели, **вайб-кодинг начинает работать так, как его рекламируют**. Ты тратишь 15 минут на ревью понятного кода вместо 15 часов на отладку выдуманных нейросетью абстрактных протоколов.

## 3. Стек и архитектура

* **Язык:** Python 3.12+
* **Фреймворк:** `aiogram 3.13+` (Router architecture, FSM, нативные платежи Telegram Stars)
* **Конфигурация:** `pydantic-settings` с защитой токена через `SecretStr` и загрузкой из `.env`
* **Персистентность:** `aiosqlite` — легковесный асинхронный журнал транзакций (`transactions.db`) для идемпотентности платежей (`telegram_payment_charge_id`) и аудита рефандов.

### Структура проекта

```text
stars-post-bot/
├── .env.example          # Шаблон переменных окружения (без секретов)
├── .gitignore            # Исключение .env, БД и кэша из Git
├── requirements.txt      # Зависимости проекта
├── config.py             # Валидация конфигурации через pydantic-settings
├── db.py                 # Журнал транзакций и защита от дублей (aiosqlite)
├── states.py             # Машина состояний (FSM)
├── bot.py                # Точка входа и запуск Long Polling
├── keyboards/
│   ├── __init__.py
│   └── inline.py         # Клавиатура инвойса (pay=True + отмена)
└── handlers/
    ├── __init__.py       # Сборка роутеров

    ├── post_submission.py# Фильтрация контента, проверка лимитов и превью

```

## 5. Быстрый старт и развертывание

### 1. Клонирование и настройка окружения

**Linux / macOS:**

```bash
git clone https://github.com/avocadonet/StarPost-Bot
cd stars-post-bot
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

```

**Windows (PowerShell):**

```powershell
git clone https://github.com/avocadonet/StarPost-Bot
cd stars-post-bot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env

```

### 2. Настройка `.env`

Заполните файл `.env` своими значениями:

* `BOT_TOKEN` — токен от `@BotFather`.
* `TARGET_GROUP_ID` — ID вашей супергруппы или канала (начинается с `-100...`).
* `STARS_PRICE` — цена одной публикации в звездах (целое число, например `50`).
* `ADMIN_ID` — ваш личный Telegram ID для получения алертов при сбоях публикации.

### 3. Запуск

```bash
python bot.py

```


## Гайд: как и через что создать и запустить такого бота с нуля

Чтобы воспроизвести этот проект или поднять его в продакшене, вам понадобятся 4 инструмента: **Telegram (`@BotFather`)**, **редактор кода (VS Code / Cursor)**, **ИИ-ассистент** (для генерации/доработки) и **любой дешевый VPS** (если бот должен работать 24/7).

### Шаг 1. Регистрация бота в Telegram (`@BotFather`)

1. Откройте в Telegram официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`, задайте отображаемое имя и юзернейм (должен заканчиваться на `bot`, например `MyStarsPosterBot`).
3. Скопируйте полученный **HTTP API Token** — это ваш `BOT_TOKEN` для файла `.env`.
4. **Нужно ли подключать платежки в `@BotFather`?**
   **Нет.** В этом и заключается главная прелесть Telegram Stars (`XTR`). Вам не нужно заходить в раздел *Payments*, заключать договоры с ЮKassa/Т-Банком или получать `provider_token`. Любой бот в Telegram умеет выставлять счета в звездах «из коробки», если в методе `send_invoice` передать `currency="XTR"` и пустой `provider_token=""`.

### Шаг 2. Подготовка целевой группы или канала и получение ID

1. Создайте группу (супергруппу) или канал, куда бот будет публиковать объявления.
2. Добавьте вашего бота в участники и **назначьте его Администратором** с правом **«Публикация сообщений»** (*Post Messages* — для каналов) или просто правом писать сообщения в группу.
3. **Как узнать `TARGET_GROUP_ID` и свой `ADMIN_ID`:**
   * Самый быстрый способ: откройте бота **[@username_to_id_bot](https://t.me/username_to_id_bot)** (или **[@userinfobot](https://t.me/userinfobot)**).
   * Пришлите ему `/start` — он сразу покажет ваш личный `ID` (это ваш `ADMIN_ID`).
   * Перешлите ему любое сообщение из вашей целевой группы/канала или отправьте ссылку на группу — он вернет ID чата со знаком минус, например `-1002145678901` (это ваш `TARGET_GROUP_ID`).

### Шаг 3. Через что проектировать и писать код (Инструментарий)

Если вы создаете такого бота с помощью ИИ (как в этом проекте), оптимальная связка выглядит так:

1. **Проектирование ТЗ в веб-чате (Gemini / Claude / ChatGPT):**
   * Не просите нейросеть сразу «написать код бота». Сначала попросите: *«Составь подробное ТЗ для монолитного Telegram-бота на aiogram 3.x для платной публикации текста за Telegram Stars без оверинжиниринга, с графом состояний FSM и таблицей граничных случаев»*.
   * Вычитайте ТЗ. Исправить одну строчку в ТЗ в 10 раз проще, чем переписывать готовый код.
2. **Сборка проекта в IDE (VS Code или Cursor):**
   * Для маленьких проектов (5–8 файлов) достаточно скопировать утвержденное ТЗ в диалог с ИИ и попросить сгенерировать все файлы проекта с защитой секретов через `.env`.
   * Если планируете дорабатывать проект (добавлять админку, статистику, модерацию), откройте папку проекта в **Cursor** или **VS Code (с расширением Continue / GitHub Copilot)** — они видят сразу все файлы в рабочей директории и могут вносить точечные правки.

### Шаг 4. Как протестировать оплату и автовозврат (Refund)

В Telegram Stars тестирование на живом боте проходит максимально просто:
1. В файле `.env` временно поставьте цену `STARS_PRICE=1` (1 звезда).
2. Запустите бота локально (`python bot.py`), отправьте ему `/start`, пришлите тестовый текст с **жирным шрифтом** и *курсивом*, и оплатите счет на **1 звезду**.
3. Убедитесь, что пост мгновенно появился в вашей группе с сохранением разметки, а бот прислал ссылку на него.
4. **Тест аварийного возврата ( и возврат вашей тестовой звезды):**
   * Удалите бота из целевой группы (или заберите у него права на отправку сообщений).
   * Снова отправьте боту текст и оплатите 1 звезду.
   * На этапе `SuccessfulPayment` бот попытается отправить пост, получит ошибку доступа от Telegram API, автоматически вызовет `bot.refund_star_payment(...)` и мгновенно вернет звезду обратно на ваш баланс, а вам в личку придет админский алерт с описанием ошибки.

### Шаг 5. Где и как хостить бота 24/7

Так как проект работает на `Long Polling` и использует встроенную базу `SQLite`, ему не нужны ни домен, ни Nginx, ни PostgreSQL:
* Подойдет самый минимальный тариф любого облачного VPS (1 vCPU, 512 МБ – 1 ГБ RAM на Ubuntu 24.04).
* Загрузите код на сервер через `git clone`, создайте на сервере файл `.env` со своими ключами и запустите бота либо через **systemd-юнит**, либо через **Docker-контейнер** с флагом `restart: unless-stopped`.
